Desktop Order Management System
A modern, high-performance desktop application built with Electron, Vite, Vue 3, and PrimeVue 4, designed to streamline and manage the complete lifecycle of customer orders. It leverages Axios for seamless client-side API communication.

Modern UI/UX: Powered by PrimeVue 4 for sleek, accessible, and responsive components (tables, dialogs, badges, and toasts).

Lightning-Fast Bundling: Built with Vite for instant HMR (Hot Module Replacement) and optimized production builds.

Robust API Integration: Built-in Axios configuration with interceptors for secure and efficient backend communication.

Cross-Platform: Runs seamlessly on Windows, macOS, and Linux via Electron.

🧰 Tech Stack
Desktop Framework: Electron

Build Tool: Vite

Frontend Framework: Vue 3 (Composition API)

UI Component Library: PrimeVue 4

HTTP Client: Axios
